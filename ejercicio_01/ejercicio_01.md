# Ejercicio 01 — Aplicaciones de IA que uso o he usado

## Objetivo

Identificar, en tu vida cotidiana o académica, sistemas que emplean inteligencia artificial y describir **cómo** los has utilizado.

## Indicaciones

Elabora una **lista de tres aplicaciones** de inteligencia artificial que uses o hayas usado.

Para cada una indica:

1. **Nombre de la aplicación** (por ejemplo: ChatGPT, Gemini, Copilot, traductor automático, recomendaciones de una plataforma, filtros de fotografía, asistente de voz, etc.).
2. **Cómo la usaste**: en qué contexto, para qué tarea y qué tipo de resultado obtuviste.

## Formato sugerido

1. **Nombre:**  Gemini

   **Uso:** Es mi principal medio para optimización del código que desarrollo, ya sea para terminar de desarrollar una idea u optimizar el código generado, igualmente lo empleo de forma indirecta dado que el buscador de Google lo implementa al momento de dar resultados para incluir un resumen de la búsqueda.

2. **Nombre:**  ChatGPT

   **Uso:** Cuando una respuesta de Gemini no me convence es cuando empleo esta IA, puesto que ambos modelos responden diferente usando el mismo prompt lo que me permite tener otra posible solución y poder decidir cuál de las dos tomar o en su caso unificarlas si es posible, otro uso que le doy es cuando el prompt requiere el análisis de una imagen como contexto para la respuesta.

3. **Nombre:** Copilot

   **Uso:** Al usar VScode el IDE incluye esta herramienta, la utilidad principal de esta está en el autocompletado o sugerencia de código, otro uso es cuando el prompt requiere de varios archivos del proyecto como contexto ya que a diferencia de las IA´s anteriores este identifica las secciones importantes en esos archivos para poder resolver la problematica.
